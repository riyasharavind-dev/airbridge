# Requirements
Local network only by default; Windows and Linux, either sender or receiver. Native application and native media pipeline. Mirror precedes genuine extended display. First-time pairing requires approval on both computers. No mock peers or fabricated readiness.

Targets: Acer Windows 11 and Lenovo Linux Mint. Exact GPU/driver and Linux session must be measured. 720p/1080p, 30 FPS and conditional 60 FPS are targets, not measured capabilities. Software codec fallback required.

Acceptance: discover and pair in both directions; reject unauthorized peers; mirror both ways; recover from interruption; report missing dependencies; verify independent OS monitor for extended mode; test fresh install and uninstall.
