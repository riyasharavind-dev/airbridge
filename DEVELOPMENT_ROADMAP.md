# Roadmap
1. Architecture, repository scaffold and first build (current).
2. Tauri foundation, real OS/GPU diagnostics, dependency checks and settings.
3. Discovery, authenticated PIN pairing, mutual approval and reconnect.
4. Native capture, H.264 transport and receiver; test Windows/Linux both ways.

7. Signed Windows installer, AppImage/deb, fresh installation and removal tests.

Each phase requires build logs, meaningful tests and explicit limitations. Stop after Phase 1 pending next instruction. Linux execution requires the Lenovo or Linux test environment.
